# Proyecto Vite + Vanilla JavaScript

Este proyecto es una aplicación frontend construida con **Vite** y **JavaScript Vanilla**, sin frameworks adicionales.  
Incluye manejo de DOM, estilos CSS y utilidades comunes.

---

## Requisitos previos

Antes de comenzar, asegúrate de tener instalado:

- **Node.js** versión 16 o superior  
  https://nodejs.org/
- **npm** (viene incluido con Node.js) o **pnpm** / **yarn**

Para verificar:

```bash
node -v
npm -v
```

### 1. Clona el repo

### 2. Instalar dependencias

Usando npm:

```bash
 npm install
```

O usando pnpm:

```bash
 pnpm install
```

### 3. Ejecutar el proyecto en modo desarrollo

```bash
  npm run dev
```

Vite levantará un servidor de desarrollo y mostrará una URL similar a:

http://localhost:5173

Abre esa URL en tu navegador para ver la aplicación.
