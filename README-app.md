# Remesas

App de gestión de remesas construida como prueba técnica front-end.

## 🚀 Demo

👉 **[Ver aplicación desplegada](https://remesas909.vercel.app/remittance?sortBy=charged_at&sortDirection=asc&perPage=5&page=1)**

## 🛠️ Tecnologías

- **Next.js 16** + **React 19** (TypeScript)
- **Material UI (MUI)** + **Emotion** para UI e iconos
- **Sass** para estilos
- **notistack** para notificaciones
- **Supabase** como backend/base de datos
- **Vercel** para el despliegue
